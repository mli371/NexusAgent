# Acme Security Handbook

## Document Handling

All internal documents must be stored in approved systems. Customer documents must not be copied into personal storage, chat tools, or unmanaged shared drives.

## Access Control

Employees should receive the minimum access needed for their role. Access reviews happen quarterly for production systems and sensitive document repositories.

## Incident Response

Suspected data exposure must be reported to the security team within one business day. The incident report should include the affected system, document category, and known timeline.

## Enterprise Support

Enterprise support requests involving customer data must include a ticket ID, the customer account, and the approved support reason. Support engineers should cite the source policy when responding.
