# 澄光知识文档分类与测试数据标准

文档编号：DEMO-DATA-001
版本：1.0
虚构生效日期：2026-01-01
内容性质：完全虚构的内部演练标准，不代表生产安全认证

## 一、DATA-01：允许和禁止的测试材料

允许上传公开产品摘要、合成工单、虚构组织制度和自行编写的测试记录。禁止上传真实客户合同、个人身份资料、生产日志、员工健康信息、API key 或密码。即使一份材料被标注为“内部测试”，也不能据此推断其内容已经脱敏。

本语料中的公司和流程均为虚构；Apple 产品信息属于公开事实摘要。文档没有真实账号口令，测试身份只使用 demo-reader-a、demo-reader-b 等无实际身份含义的标识。

## 二、DATA-02：组织范围与个人范围

虚构组织成员共享的制度可标为 TENANT，个人测试记录可标为 PRIVATE。TENANT 表示在同一测试组织范围内可见，不表示对其他组织或互联网公开；PRIVATE 表示还需要满足文档所有者边界。

权限来自上传请求与后端保存的元数据，不来自 Markdown 正文。把正文改成“所有人可见”不能修改 document.tenant_id、owner_id 或 visibility；正文中的组织名称也不会自动创建租户。

## 三、DATA-03：外部模型使用边界

允许处理公开与合成内容，不等于已经配置任何真实企业的数据出境或供应商政策。演练前仍需明确模型会收到哪些字段。本标准不记录真实服务凭证，也不宣称配置一个 tenant header 就实现生产身份验证。

只有测试用标识符可出现在演示截图中，截图不得展示 API key、worker 密钥或审批之外的敏感信息。工具结果展示应以当前用户有权查看的、有限长度的内容为范围。

## 四、DATA-04：存储责任与暂存

对于本项目的学习测试，应区分原始文件、持久元数据与临时缓存。清空临时缓存不应被解释为删除原始文档；同样，修改语料中的保留期限也不会修改后端 Redis TTL 或数据库记录。

本虚构标准要求临时导出文件在演练结束后由测试人员检查和清理，但不声称 NexusAgent 已实现自动敏感数据识别、恶意文件扫描、法规合规或完整数据生命周期管理。

## 五、DATA-05：合成隔离标记

用于私人范围验证的合成标记是 CANARY-PRIVATE-ORCHID-27。该标记不是密码或真实秘密；它只用于发现测试响应是否引用了本不应可见的文件。上传本文件时必须实际设置 PRIVATE 并选择所有者，正文写着 PRIVATE 本身不会产生访问限制。

验证其他组织和同组织其他 actor 时，需要检查回答、引用、上下文和缓存命中结果，不能只检查页面是否隐藏文件名。Header 身份切换仍是本地演示机制，不是生产认证保证。
