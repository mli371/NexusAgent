# 第三步：双范围知识问答与学习前端

用户已批准原问答前端设计，并明确批准两种检索范围：默认整个可访问知识库，可选指定文档。无需重新开始设计审批。

## 已定边界

- `scope=library` 默认按后端 tenant/PRIVATE 和当前模型覆盖率选择就绪文档；两条检索路径使用同一个请求级文档快照。
- `scope=documents` 要求 1–10 份明确文档且全部就绪。旧请求带 documentIds 时仍视为指定模式。
- 返回范围统计和未就绪原因计数；绝不静默只取前十份。学习版全库扫描最多 200 份可访问文档，超过时明确拒绝并要求指定范围，不伪装全库搜索。
- 默认知识问答页，保留独立 Pi 文档处理入口。复用 React、Lucide 和当前清爽三栏样式，不新增框架。
- 问答仅调用真实模式；离线或旧后端显示未就绪，不调用模板假装真实回答。API key 留在后端。
- POST SSE 只提交一次，不断线重发；切换身份/退出视图取消本地请求并清空敏感数据。问答记录仅保留当前页面内存，最多 12 条。
- 真实阶段 DAG、摘要、最终授权候选/上下文和静态源码职责分开展示；不展示隐藏推理，不伪造 token。
- 文档准备仍走原审批页面；替换旧模型向量是单独明确确认的付费写操作，不混入普通问答。
- 不自动修改 `.env`、不迁移已有向量、不代替用户审批；真实付费验收单独明确确认。
