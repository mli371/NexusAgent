## Review 重点

1. `LiveContextService`：源指纹/权限/revision 复查，精确/语义路径分支和无别名写入。
2. `SemanticReusePolicy`：词面规则是有限启发式，不是意图模型。
3. `RedisSemanticContextCache` 与 Lua：最多读取/写入的条目、来源大小和过期时间。
4. 前端阶段图：语义命中时 query_embedding 仍执行，检索/重排数据属于缓存源问题。

## 保留限制与面试答法

0.96 是未标定的默认阈值，不代表正确率；相似意图不保证所需证据相同。未知、多个已识别否定或混合意图可保守地绕过语义层；未覆盖的实体/意图差异仍可能误命中。容量只限制每个 scope，不是全局配额。Header 身份不是认证；向量与摘要不是匿名数据。

面试时应说：实现了有界、tenant/version-scoped 的实验性语义上下文复用，有明确过期、失败回退及防链式漂移规则；未做生产性能或真实语义质量承诺。完整说明和命令见 [学习笔记](../learning/semantic-context-cache.md)。
